## Как пользоваться

1. Откройте Excel и идите по листам сверху вниз или по слабым темам.
2. На листе «Резюме_и_поведение» подставьте факты из вашего PDF-резюме (годы, проекты, цифры).
3. Перегенерировать файл: `python3 generate_interview_prep.py  # из этой папки` (нужен `openpyxl`).

## Примечание об исходниках

Пути к файлам на Windows (`Собес имени меня.xlsx`, `Собеседование.xlsx`, `Резюме_....pdf`) в облачную среду не загрузились. Вопросы и ответы составлены заново с учётом ваших требований (рефлексия, интерфейсы, JOIN и расширенный SQL, Creatio). Если пришлёте эти файлы в чат агента вложением, можно дополнить документ точными вопросами из ваших таблиц.
