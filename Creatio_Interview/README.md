# Подготовка к собеседованию Creatio / BPMSoft (простым языком)

Папка для Владислава Пыжьянова: вопросы и ответы **«для чайников»** — с аналогиями, шагами и блоком **«Что сказать»** на собеседовании.

## Файлы

- [Creatio_Interview_QA_Pyzhyanov.xlsx](./Creatio_Interview_QA_Pyzhyanov.xlsx) — основной файл (латинское имя)
- [Собеседование_Creatio_Ответы_Владислав_Пыжьянов.xlsx](./Собеседование_Creatio_Ответы_Владислав_Пыжьянов.xlsx) — то же содержимое

### Листы

| Лист | Зачем |
|------|--------|
| Содержание | Как читать файл |
| C# | Рефлексия, интерфейсы, OOP, Creatio server |
| SQL | JOIN и практика |
| JavaScript | Язык + клиент Creatio |
| Creatio_BPMSoft | Платформа и кейсы |
| Архитектура_очереди | IIS, Redis, БД, RabbitMQ, Kafka |
| Резюме_и_поведение | О себе, STAR — **впишите факты из резюме** |
| Как_готовиться | Пошаговый план |
| SQL_шпаргалка | Готовые запросы с пояснениями |

Колонка **Статус** — отмечайте `ок` / `повторить`.

## Пересобрать Excel

```bash
pip install openpyxl
python3 generate_interview_prep.py
```
